# BazarDor (বাজার দর)

BazarDor is a web application for exploring essential product prices in
Bangladesh.

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- MongoDB
- Better Auth

## Features

1. Responsive design
2. Product browsing
3. Category navigation
4. Product details
5. User sign up and sign in
6. User profile
7. Product price information

## React Questions

**2. What are Props?**  
Props pass data from one component to another.

**3. What is State?**  
State stores data that can change over time.

**4. What is useState?**  
A React Hook used to manage component state.

**5. What is useEffect?**
